# IT-термины перед C#

Статичный учебный сервис для студентов, которые только начинают изучать C# и пока не уверенно понимают базовые IT-термины.

Сейчас в базе 189 терминов: базовое IT-окружение, жизненный цикл ПО, C#/.NET, Git/GitHub, выполнение программы под капотом, файлы сборки проекта, короткий обзор ООП, переменные, типы данных, ввод, операции, преобразования, условия и ветвление.

## Что есть

- Карточки с тренировкой: термин на одной стороне, пояснение на другой.
- В карточках кнопка `Повторить позже` отправляет текущую карточку в конец колоды, а `Понял` двигает прогресс вперед.
- Тесты в двух направлениях: термин -> пояснение и пояснение -> термин.
- 30 разобранных примеров C# для терминов из ЛБ 4–6: они видны в справочнике и на обороте карточек.
- Отдельная практика «Понимаю код» с вопросами о результате, строке кода и причинах ошибки; после ответа показывается объяснение.
- Группировка по темам и колодам.
- Справочник с поиском, сортировкой и фильтрами.
- Цветные метки в справочнике: тема, колода и лабораторная работа (`ЛБ 1` - `ЛБ 6`).
- Фильтр по меткам, включая быстрый отбор терминов по лабораторной работе.
- Темная тема.
- Предупреждение при выходе из активной тренировки.
- Хранение только в браузере: сейчас сохраняется только выбранная тема оформления.

## Где менять термины

Все термины находятся в `app.js` в массиве `topics`. Примеры и задания находятся в `code-content.js` в массиве `codeLessons`. Каждый элемент связан с термином парой `deckId` + `term`; для нового задания сначала добавьте соответствующий термин в колоду.

Фрагменты C# показаны как текст: сайт не запускает их в браузере. Для задания можно указать `challengeInput`, а правильный вариант задаётся индексом `correctIndex` в массиве `options`. Ответ должен сопровождаться пояснением `explanation`.

Проверка учебных данных: `node --test tests/content.test.mjs`. Если установлен .NET SDK, команда `node tests/verify-examples.mjs` компилирует все примеры в временном проекте и сверяет их вывод.

Структура:

```js
{
  id: "topic-id",
  title: "Название темы",
  description: "Описание темы",
  decks: [
    {
      id: "deck-id",
      title: "Название колоды",
      terms: [
        {
          term: "Термин",
          definition: "Пояснение"
        }
      ]
    }
  ]
}
```

Рекомендуемый размер колоды для новичков: 10-12 терминов.

## Как открыть

Можно просто открыть `index.html` в браузере.

Для локальной проверки через простой сервер:

```bash
python -m http.server 5507
```

После этого открыть:

```text
http://127.0.0.1:5507/
```

## GitHub Pages

Для публикации достаточно положить `index.html`, `styles.css`, `code-content.js`, `app.js` и `README.md` в репозиторий GitHub, затем включить GitHub Pages для нужной ветки и папки.
