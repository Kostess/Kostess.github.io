# IT-термины перед C#

Статичный учебный сервис для студентов, которые только начинают изучать C# и пока не уверенно понимают базовые IT-термины.

Сейчас в базе 209 терминов: базовое IT-окружение, жизненный цикл ПО, C#/.NET, Git/GitHub, выполнение программы под капотом, файлы сборки проекта, короткий обзор ООП, переменные, типы данных, ввод, операции, преобразования, условия, ветвление и циклы.

## Что есть

- Карточки с тренировкой: термин на одной стороне, пояснение на другой.
- В карточках кнопка `Повторить позже` отправляет текущую карточку в конец колоды, а `Понял` двигает прогресс вперед.
- Тесты в двух направлениях: термин -> пояснение и пояснение -> термин.
- 150 разобранных примеров C# для терминов из ЛБ 4–7: они видны в справочнике и на обороте карточек.
- У 24 заданий есть по две альтернативные версии (48 дополнительных вопросов). При старте выбирается версия, а варианты ответа перемешиваются во всех заданиях. Объяснение соответствует выбранному коду.
- Отдельная практика «Понимаю код» с вопросами о результате, строке кода и причинах ошибки; после ответа показывается объяснение.
- В практике «Понимаю код» на каждое задание даётся 90 секунд. По истечении времени ответы блокируются, показываются правильный вариант и объяснение; задание не приносит балл. Следующее задание открывается кнопкой.
- Группировка по темам и колодам.
- Справочник с поиском, сортировкой и фильтрами.
- Цветные метки в справочнике: тема, колода и лабораторная работа (`ЛБ 1` - `ЛБ 7`).
- Фильтр по меткам, включая быстрый отбор терминов по лабораторной работе.
- Темная тема.
- Предупреждение при выходе из активной тренировки.
- Прогресс хранится в этом браузере: ответы в карточках, тесте и практике, число попыток и ошибки. На главной видны пройденные термины и список для повторения. В каждом режиме есть фильтр повторения в выбранной теме/подборке; карточки могут повторять термины из ошибок всех режимов. Верный ответ снимает отметку ошибки в соответствующем режиме, история попыток остаётся.
- В обычном тесте после ответа показаны правильный вариант и определение термина. Переход — кнопкой «Далее», без автоматического таймера.
- Ответы записываются сразу, включая незавершённые тренировки. После перезагрузки можно начать новую тренировку с учётом сохранённых ошибок; текущий вопрос не восстанавливается. Прогресс не переносится между устройствами и удаляется при очистке данных сайта.

База содержит 150 основных заданий в 17 колодах: ЛБ 4 — 40, ЛБ 5 — 40, ЛБ 6 — 40, ЛБ 7 — 30. Помимо вычисления вывода есть выбор пропущенной строки или оператора и подсчёт итераций.

В «Понимаю код» сначала выберите лабораторную, затем колоду. Каждая тренировка содержит 5–10 заданий; фильтр ошибок оставляет только ошибки выбранной колоды.

## Уровень примеров

Примеры соответствуют вводному курсу: переменные и типы, преобразования, арифметика, сравнения, логика, ветвление и циклы. В ЛБ 4–5 нет ветвления; оно появляется с ЛБ 6. В практике нет nullable-обозначений, null, обработки исключений, TryParse/out, получения типа через GetType, настроек культуры и специальных форматов чисел. Тернарный оператор, числовые суффиксы, вложенные циклы и чтение счётчика после пустого цикла сохранены. Вложенные циклы оформляются с фигурными скобками.

Для заданий с вводом предполагается, что пользователь вводит указанные данные, включая команду завершения цикла. Проверка неправильного ввода и окончания потока пока не изучается.

## Где менять термины

Все термины находятся в `terms-content.js` в массиве `topics`. Примеры и задания находятся в `code-content.js` в массиве `codeLessons`. Каждый элемент связан с термином парой `deckId` + `term`; для нового задания сначала добавьте соответствующий термин в колоду.

В `code-content.js` массив `codeDecks` задаёт колоды практики (`id`, `lab`, `title`), а поле `codeDeckId` каждого задания связывает его с одной колодой. В колоде должно быть 5–10 примеров. Несколько заданий могут ссылаться на один термин через `deckId` + `term`; каждое задание имеет уникальный стабильный `id`. Ошибки практики учитываются отдельно по `id`, чтобы ответ в одном примере не снимал ошибку другого. Старые записи по термину автоматически относятся к исходному заданию. В справочнике показаны все связанные примеры; на карточке — первый.

Фрагменты C# показаны как текст: сайт не запускает их в браузере. Для задания можно указать `challengeInput`, а правильный вариант задаётся индексом `correctIndex` в массиве `options`. Ответ должен сопровождаться пояснением `explanation`. Дополнительные версии хранятся в `variants`: у каждой свои `challengeCode`, `options`, `correctIndex`, `explanation` и `challengeResult` для проверки через .NET. Связь со словарём и колодой наследуется от основного задания. Не меняйте основное задание при перемешивании ответов.

Для вопросов «Заполните пропуск» используется маркер `/* ??? */` и поле `solutionResult`. Проверка подставляет выбранный правильный вариант в маркер, компилирует полученный C# и сверяет вывод с `solutionResult`.

Проверка данных и поведения тренировок: `node --test tests/*.test.mjs`. Если установлен .NET SDK, команда `node tests/verify-examples.mjs` компилирует все примеры в временном проекте и сверяет их вывод, а также ответы новых исполняемых заданий из поля `challengeResult`.

Структура:

```js
{
  id: "topic-id",
  title: "Название темы",
  description: "Описание темы",
  decks: [
    {
      id: "deck-id",
      title: "Название колоды",
      terms: [
        {
          term: "Термин",
          definition: "Пояснение"
        }
      ]
    }
  ]
}
```

Рекомендуемый размер колоды для новичков: 10-12 терминов.

## Как открыть

Можно просто открыть `index.html` в браузере.

Для локальной проверки через простой сервер:

```bash
python -m http.server 5507
```

После этого открыть:

```text
http://127.0.0.1:5507/
```

## GitHub Pages

Для публикации достаточно положить `index.html`, `styles.css`, `terms-content.js`, `code-content.js`, `app.js` и `README.md` в репозиторий GitHub, затем включить GitHub Pages для нужной ветки и папки.
