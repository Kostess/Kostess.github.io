    C#

    Открытое задание · Разбей Main на методы

    Скопируй программу в отдельный проект и сначала запусти её как есть. Затем выдели метод подсчёта и метод вывода отчёта. После изменений в Main должно быть видно, какие данные проверяются и в каком порядке выводятся результаты.

    Program.cs 
    using System;

class Program
{
    static void Main()
    {
        int[] morning = { 180, 250, 320 };
        int[] evening = { 250, 410, 480 };
        int limit = 250;

        int morningCount = 0;
        foreach (int time in morning)
        {
            if (time > limit)
            {
                morningCount++;
            }
        }
        Console.WriteLine($"Утро: выше {limit} мс — {morningCount}");

        int eveningCount = 0;
        foreach (int time in evening)
        {
            if (time > limit)
            {
                eveningCount++;
            }
        }
        Console.WriteLine($"Вечер: выше {limit} мс — {eveningCount}");
    }
}

    Сверь вывод после рефакторинга

    Утро: выше 250 мс — 1
Вечер: выше 250 мс — 2
    • Один метод считает для обоих массивов. Он принимает массив и порог, возвращает число и оставляет массив без изменений.
    • Другой метод выводит готовый результат с подписью.
    • Замер, равный порогу, по-прежнему не учитывается. Объясни, где это проверяется и почему ты выделил именно эти два метода.
